# Налоговые данные движка

Здесь лежит всё, из чего собираются `backend/app/engine/countries.json` и `backend/app/engine/legal_forms.json`. Эти два файла руками не правятся: правка делается в источниках или в `build.py`, затем данные пересобираются.

## Пересборка

```bash
python3 backend/tools/tax_data/build.py
```

Скрипт печатает число стран, режимов и форм юрлиц, список полей, которые остались пустыми, и всё, что он отбросил. Тест `backend/tests/test_data_build.py` падает, если файлы в `app/engine/` не совпадают с результатом сборки.

## Что где

- `sources/*.json`: исследования по регионам, по одному объекту на страну. Формат: ставки подоходного налога, взносы, НДС, дедлайны, ставка резерва, источники, формы юрлиц.
- `build.py`: проверяет и нормализует источники и пишет два файла данных. В нём же лежат ручные правки:
  - `DISPLAY`: короткие названия и подсказки для режимов из демо;
  - блок про Эстонию: деление 22/55 и 33/55, дедлайны и правило словами, сверенные с первоисточниками;
  - `SHORT_ANY_CASE`, `SHORT_EXACT`, `CAPS_SAFE`: какие короткие формы юрлиц оставлять, чтобы не путать их с именами людей;
  - `ALLOWANCE_IS_A_CREDIT`, `ZERO_DECIMAL_STORED_X100`: поправки для Исландии.

## Насколько данным можно верить

- **Эстония** сверена 13.11.2026 с сайтом EMTA и текстом закона в Riigi Teataja. У этих режимов `verification` равно `official`.
- **Остальные 78 стран** собраны ИИ-агентами в основном из сводок PwC и консалтинговых сайтов: сайты налоговых органов почти не открывались. У них `verification` равно `secondary`.
- Ставки резерва (`suggestedReserveRateBp`) посчитаны на предположенном доходе, арифметика записана в `reserveBasis`.
- Формы юрлиц записаны по памяти моделей и по реестрам не сверялись.
- У каждого режима есть `sources`, `verifiedAt`, `notes` и список `unverified` с полями, которые остались пустыми.

Перед показом цифр по любой стране, кроме Эстонии, их нужно сверить с официальным источником.

## Единицы

Суммы в минорных единицах валюты по ISO 4217: центы для EUR и USD, целые единицы для JPY, KRW и CLP, тысячные для KWD и BHD. Исландская крона в источнике записана в сотых и при сборке делится на 100. Ставки в базисных пунктах.
